# job-radar v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v1 of job-radar — upload a resume, extract/edit a structured profile, fetch RemoteOK job listings, score them against the profile, and show ranked matches.

**Architecture:** Next.js App Router app. Framework-agnostic logic lives in `lib/` (resume parsing, Claude Code subprocess calls, SQLite storage, RemoteOK fetch, keyword prefilter, LLM fit-scoring, refresh orchestration), called from thin `app/api/*/route.ts` handlers and two client pages (`/resume`, `/jobs`).

**Tech Stack:** Next.js (App Router) + TypeScript + Tailwind, `node:sqlite` (Node built-in, Node 24+), zod, pdf-parse + mammoth, Claude Code headless subprocess (`claude -p`), vitest.

**Amendment (post Task 1, 2026-10-06):** The spec and this plan originally called for `better-sqlite3` specifically to avoid a Node 24+ floor. In practice, `better-sqlite3@11.10.0`'s native addon fails to compile against this machine's Node v26.7.0 (`npm rebuild better-sqlite3` errors: `no member named 'This' in 'v8::PropertyCallbackInfo<v8::Value>'` — the V8 embedder API it targets was removed). Since this machine already runs Node 26 (exceeds the 24+ floor the original choice was trying to avoid), and `node:sqlite`'s `DatabaseSync` requires no native compilation at all, Task 2 below uses `node:sqlite` instead. Verified working end-to-end (`new DatabaseSync(path)`, `.exec()`, `.prepare().run()/.get()/.all()`, `lastInsertRowid`) before this amendment was made. Task 1's `package.json` drops the `better-sqlite3`/`@types/better-sqlite3` entries as part of Task 2.

**Spec:** `docs/superpowers/specs/2026-10-05-job-radar-design.md`

## Global Constraints

- Single-user, local, no auth (spec: "Non-goals (v1)").
- One job source only — RemoteOK (spec: "Non-goals (v1)").
- No scheduled/cron refresh — manual refresh button only (spec: "Non-goals (v1)").
- `claude` subprocess env must never forward `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, or `ANTHROPIC_WORKSPACE_ID` (spec: "Tech stack").
- Storage uses `node:sqlite` (`DatabaseSync`) — amended 2026-10-06 from the original `better-sqlite3` choice; see "Amendment" note above the Tech Stack line.
- All persisted data lives under a data directory overridable via `JOB_RADAR_DATA_DIR` env var, default `data/` (spec: "Data model").
- Never write partial/invalid JSON into `profile.json` or `score_cache` on extraction/scoring failure (spec: "Error handling").

## Review Focus

- Resume upload with an unsupported file type (e.g. `.txt`, `.jpg`) must return a clear 400, not throw unhandled — Task 4 (dispatch) and Task 7 (route) tests.
- Running the job refresh before any profile has been saved must fail with a controlled, readable error, not crash on `null.roles` — Task 13 (pipeline) and Task 14 (route) tests.
- RemoteOK's API response includes a non-job legal-notice object as its first array element — it must be filtered out, not crash the mapping — Task 10 test.
- Claude Code returning non-JSON or schema-invalid output (model hallucination) during extraction or scoring must be rejected, never silently saved — Task 6 and Task 12 tests.
- Re-running refresh with the same RemoteOK response must be idempotent — no duplicate rows, no re-scoring already-cached jobs — Task 13 test.

- [ ] **Step 4: Write `lib/db.ts`**

Uses `node:sqlite`'s `DatabaseSync` (Node built-in, no native addon to compile — see the plan's Amendment note; confirmed working on this machine's Node v26.7.0). Its API is sync like `better-sqlite3`: `db.exec(sql)`, `db.prepare(sql).run(params)/.get(params)/.all(params)`, `run()` returns `{ changes, lastInsertRowid }`, and named params use `@name` the same way.

```ts
import { DatabaseSync } from "node:sqlite";
import fs from "node:fs";
import path from "node:path";
import type { JobRow, ScoreResult } from "./types";

let db: DatabaseSync | null = null;

function dataDir(): string {
  const dir = process.env.JOB_RADAR_DATA_DIR ?? path.join(process.cwd(), "data");
  fs.mkdirSync(dir, { recursive: true });
  return dir;
}

export function getDb(): DatabaseSync {
  if (db) return db;
  db = new DatabaseSync(path.join(dataDir(), "jobs.db"));
  db.exec(`
    CREATE TABLE IF NOT EXISTS jobs (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      source TEXT NOT NULL,
      source_id TEXT NOT NULL,
      title TEXT NOT NULL,
      company TEXT NOT NULL,
      url TEXT NOT NULL,
      description TEXT NOT NULL,
      posted_at TEXT,
      fetched_at TEXT NOT NULL,
      dedupe_key TEXT NOT NULL UNIQUE,
      prefilter_score REAL,
      fit_score REAL,
      reason TEXT,
      matched_skills TEXT
    );
    CREATE TABLE IF NOT EXISTS score_cache (
      cache_key TEXT PRIMARY KEY,
      fit_score REAL NOT NULL,
      reason TEXT NOT NULL,
      matched_skills TEXT NOT NULL,
      created_at TEXT NOT NULL
    );
  `);
  return db;
}

export function resetDbForTests(): void {
  if (db) {
    db.close();
    db = null;
  }
}

function rowToJobRow(row: any): JobRow {
  return {
    id: row.id,
    source: row.source,
    sourceId: row.source_id,
    title: row.title,
    company: row.company,
    url: row.url,
    description: row.description,
    postedAt: row.posted_at,
    fetchedAt: row.fetched_at,
    dedupeKey: row.dedupe_key,
    prefilterScore: row.prefilter_score,
    fitScore: row.fit_score,
    reason: row.reason,
    matchedSkills: row.matched_skills ? JSON.parse(row.matched_skills) : null,
  };
}

export function insertJob(job: Omit<JobRow, "id">): number {
  const conn: DatabaseSync = getDb();
  const existing = conn
    .prepare("SELECT id FROM jobs WHERE dedupe_key = ?")
    .get(job.dedupeKey) as { id: number } | undefined;
  if (existing) return existing.id;

  const result = conn
    .prepare(
      `INSERT INTO jobs (source, source_id, title, company, url, description, posted_at, fetched_at, dedupe_key, prefilter_score, fit_score, reason, matched_skills)
       VALUES (@source, @sourceId, @title, @company, @url, @description, @postedAt, @fetchedAt, @dedupeKey, @prefilterScore, @fitScore, @reason, @matchedSkills)`
    )
    .run({
      ...job,
      matchedSkills: job.matchedSkills ? JSON.stringify(job.matchedSkills) : null,
    });
  return Number(result.lastInsertRowid);
}

export function getJobs(): JobRow[] {
  const conn = getDb();
  const rows = conn
    .prepare(
      "SELECT * FROM jobs ORDER BY fit_score IS NULL ASC, fit_score DESC, fetched_at DESC"
    )
    .all();
  return rows.map(rowToJobRow);
}

export function updateJobPrefilter(id: number, score: number): void {
  getDb().prepare("UPDATE jobs SET prefilter_score = ? WHERE id = ?").run(score, id);
}

export function updateJobScore(id: number, result: ScoreResult): void {
  getDb()
    .prepare("UPDATE jobs SET fit_score = ?, reason = ?, matched_skills = ? WHERE id = ?")
    .run(result.fit_score, result.reason, JSON.stringify(result.matched_skills), id);
}

export function getCachedScore(cacheKey: string): ScoreResult | null {
  const row = getDb()
    .prepare("SELECT fit_score, reason, matched_skills FROM score_cache WHERE cache_key = ?")
    .get(cacheKey) as { fit_score: number; reason: string; matched_skills: string } | undefined;
  if (!row) return null;
  return {
    fit_score: row.fit_score,
    reason: row.reason,
    matched_skills: JSON.parse(row.matched_skills),
  };
}

export function setCachedScore(cacheKey: string, result: ScoreResult): void {
  getDb()
    .prepare(
      `INSERT OR REPLACE INTO score_cache (cache_key, fit_score, reason, matched_skills, created_at)
       VALUES (?, ?, ?, ?, ?)`
    )
    .run(cacheKey, result.fit_score, result.reason, JSON.stringify(result.matched_skills), new Date().toISOString());
}
```

Note: `ORDER BY fit_score IS NULL ASC, fit_score DESC` sorts non-null scores first (highest first), nulls last — SQLite evaluates `fit_score IS NULL` as 0/1.

```ts
import fs from "node:fs";
import path from "node:path";
import type { Profile } from "./types";

export function getDataDir(): string {
  const dir = process.env.JOB_RADAR_DATA_DIR ?? path.join(process.cwd(), "data");
  fs.mkdirSync(dir, { recursive: true });
  return dir;
}

export function readProfile(): Profile | null {
  const file = path.join(getDataDir(), "profile.json");
  if (!fs.existsSync(file)) return null;
  return JSON.parse(fs.readFileSync(file, "utf8")) as Profile;
}

export function writeProfile(profile: Profile): void {
  const file = path.join(getDataDir(), "profile.json");
  fs.writeFileSync(file, JSON.stringify(profile, null, 2));
}

export function writeResumeFile(buffer: Buffer, filename: string): void {
  fs.writeFileSync(path.join(getDataDir(), filename), buffer);
}
```

```ts
export async function extractResumeText(buffer: Buffer, filename: string): Promise<string> {
  const ext = path.extname(filename).toLowerCase();

  }
  if (ext === ".docx") {

    return result.value;
```

```ts
import { spawn } from "node:child_process";

export interface RunClaudeCodeOptions {
  prompt: string;
  cwd?: string;
  model?: string;
}

export function runClaudeCode(options: RunClaudeCodeOptions): Promise<string> {
  return new Promise((resolve, reject) => {
    const env = { ...process.env };
    delete env.ANTHROPIC_API_KEY;
    delete env.ANTHROPIC_AUTH_TOKEN;
    delete env.ANTHROPIC_WORKSPACE_ID;

    const args = ["-p", options.prompt, "--output-format", "json"];
    if (options.model) args.push("--model", options.model);

    const child = spawn("claude", args, { cwd: options.cwd, env });

    let stdout = "";
    let stderr = "";
    child.stdout.on("data", (chunk) => (stdout += chunk.toString()));
    child.stderr.on("data", (chunk) => (stderr += chunk.toString()));
    child.on("close", (code) => {
      if (code === 0) resolve(stdout);
      else reject(new Error(stderr || `claude exited with code ${code}`));
    });
  });
}
```

```ts
  const form = await req.formData();
```

```ts
import type { Profile, RawJob } from "./types";

const MAX_AGE_DAYS = 90;

export interface PrefilterResult {
  score: number;
  passed: boolean;
}

export function prefilterJob(job: RawJob, profile: Profile): PrefilterResult {
  if (!job.title || !job.description) {
    return { score: 0, passed: false };
  }

  if (job.postedAt) {
    const ageMs = Date.now() - new Date(job.postedAt).getTime();
    if (ageMs > MAX_AGE_DAYS * 24 * 60 * 60 * 1000) {
      return { score: 0, passed: false };
    }
  }

  const haystack = `${job.title} ${job.description}`.toLowerCase();
  const keywords = [...profile.skills, ...profile.roles.map((r) => r.title)];

  let score = 0;
  for (const keyword of keywords) {
    const needle = keyword.trim().toLowerCase();
    if (needle && haystack.includes(needle)) score += 1;
  }

  return { score, passed: score > 0 };
}
```

```ts
import crypto from "node:crypto";
import { z } from "zod";
import { runClaudeCode } from "./claudeCode";
import { getCachedScore, setCachedScore } from "./db";
import type { Profile, RawJob, ScoreResult } from "./types";

export const SCORE_SCHEMA = z.object({
  fit_score: z.number().min(0).max(100),
  reason: z.string(),
  matched_skills: z.array(z.string()),
});

export function buildCacheKey(profile: Profile, job: RawJob): string {
  const payload = JSON.stringify({ profile, jobId: job.sourceId, description: job.description });
  return crypto.createHash("sha256").update(payload).digest("hex");
}

export async function scoreJob(job: RawJob, profile: Profile): Promise<ScoreResult> {
  const cacheKey = buildCacheKey(profile, job);
  const cached = getCachedScore(cacheKey);
  if (cached) return cached;

  const prompt = [
    "Score how well this candidate fits this job, 0-100, as JSON only, no prose.",
    'Shape: {"fit_score":number,"reason":string,"matched_skills":string[]}',
    `Candidate skills: ${profile.skills.join(", ")}`,
    `Candidate summary: ${profile.summary}`,
    `Job title: ${job.title}`,
    `Job description: ${job.description}`,
  ].join("\n");

  const output = await runClaudeCode({ prompt });

  let parsed: unknown;
  try {
    parsed = JSON.parse(output);
  } catch {
    throw new Error("Claude Code did not return valid JSON for job scoring");
  }

  const result = SCORE_SCHEMA.parse(parsed);
  setCachedScore(cacheKey, result);
  return result;
}
```

```ts
import { fetchRemoteOkJobs } from "./sources";
import { prefilterJob } from "./prefilter";
import { scoreJob } from "./scorer";
import { readProfile } from "./store";
import { insertJob, updateJobPrefilter, updateJobScore } from "./db";
import type { RawJob } from "./types";

export interface RefreshDeps {
  fetchRemoteOkJobs: () => Promise<RawJob[]>;
  prefilterJob: typeof prefilterJob;
  scoreJob: typeof scoreJob;
  readProfile: typeof readProfile;
  insertJob: typeof insertJob;
  updateJobPrefilter: typeof updateJobPrefilter;
  updateJobScore: typeof updateJobScore;
}

export interface RefreshSummary {
  fetched: number;
  inserted: number;
  scored: number;
}

const defaultDeps: RefreshDeps = {
  fetchRemoteOkJobs,
  prefilterJob,
  scoreJob,
  readProfile,
  insertJob,
  updateJobPrefilter,
  updateJobScore,
};

export async function refresh(deps: Partial<RefreshDeps> = {}): Promise<RefreshSummary> {
  const d = { ...defaultDeps, ...deps };

  const profile = d.readProfile();
  if (!profile) throw new Error("No profile saved yet");

  const rawJobs = await d.fetchRemoteOkJobs();
  let inserted = 0;
  let scored = 0;

  for (const job of rawJobs) {
    const result = d.prefilterJob(job, profile);
    if (!result.passed) continue;

    const id = d.insertJob({
      source: "remoteok",
      sourceId: job.sourceId,
      title: job.title,
      company: job.company,
      url: job.url,
      description: job.description,
      postedAt: job.postedAt,
      fetchedAt: new Date().toISOString(),
      dedupeKey: `remoteok:${job.sourceId}`,
      prefilterScore: result.score,
      fitScore: null,
      reason: null,
      matchedSkills: null,
    });
    d.updateJobPrefilter(id, result.score);
    inserted += 1;

    const scoreResult = await d.scoreJob(job, profile);
    d.updateJobScore(id, scoreResult);
    scored += 1;
  }

  return { fetched: rawJobs.length, inserted, scored };
}
```

`insertJob` (Task 2) returns the existing row id for a duplicate `dedupeKey` instead of inserting again, so `jobs` never gets duplicate rows across runs. Re-billing avoidance on repeat runs comes entirely from `scoreJob`'s own content-hash cache (Task 12) — `refresh()` itself always calls `insertJob`/`scoreJob` for every prefilter-passing job on every run; it does not track "is this job new to this run" itself. `RawJob` is imported from `./types` for the `RefreshDeps.fetchRemoteOkJobs` signature above.
